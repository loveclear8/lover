# 我们的故事 · 未完待续

一个不用安装、双击就能打开的纪念网站。  
里面有星夜、时间轴、照片墙、情书、愿望清单、会连成心形的星座，还有实时生成的背景音乐和满屏爱心。

---

## 1. 怎么打开

双击 **`index.html`** 即可。

推荐使用 **Chrome / Edge / Safari 最新版**。  
手机浏览器也能看，页面会自动适配。

> 如果你想发给女朋友，直接把整个文件夹压缩发过去，或者部署到网上（见第 5 节）。

---

## 2. 先改成你们的故事

所有内容都集中在 **`js/config.js`** 里，打开就能改，不需要懂代码。

最优先改这 4 个地方：

```js
her: "宝贝",              // 她的名字 / 昵称
me: "你的男孩",            // 你的名字 / 昵称
startDate: "2022-05-20T20:20:00+08:00",  // 在一起的准确时间
sinceLabel: "2022.05.20",  // 页面上显示的纪念日
sinceLong: "2022 年 5 月 20 日",  // 正文里使用的日期
```

改完之后，首页“在一起第几天”、文末“第 N 天”、纪念日文字都会自动更新。

### 修改首页文案

```js
hero: {
  title1: "我们的故事",
  title2: "未完待续",
  subtitle: "从 {sinceLong}那天起，我的世界多了一个让我心软的理由。",
  typed: [
    "你是我所有温柔的来源。",
    "也是我未来每一个计划里的名字。",
    "余生请多指教，我的宝贝。"
  ]
}
```

`typed` 里的三句话会轮流打字显示。  
`{sinceLong}`、`{her}`、`{me}` 是自动替换的占位符。

## 3. 换照片

照片文件放在 **`assets/`** 文件夹里。

当前用的是手绘插画占位图。换成你们的照片时：

1. 把照片放进 `assets/`，例如 `assets/us-01.jpg`；
2. 在 `js/config.js` 里找到 `timeline` 或 `gallery`；
3. 把对应的 `image` / `src` 改成新文件名。

示例：

```js
{
  date: "2022.05.20",
  tag: "初见",
  title: "故事开始的地方",
  text: "那天人很多，灯很亮，我却只记住了你笑起来的样子。",
  image: "assets/us-01.jpg",
  caption: "第一次约会 · 2022",
  alt: "第一次约会时的合照"
}
```

### 建议尺寸

- 时间轴 / 照片墙：竖图 **4:5**，例如 1200 × 1500
- 首页圆形主图：方图 **1:1**，例如 1200 × 1200
- 文件不要太大，单张建议 1MB 以内，打开更快

首页那张圆形图在 `index.html` 里：

```html
<img src="assets/hero.svg" alt="">
```

把 `assets/hero.svg` 换成你的照片路径即可。

## 4. 继续改内容

### 时间轴

`config.timeline` 数组，每一项对应一个回忆：

```js
{
  date: "2022.05.20",
  tag: "初见",
  title: "故事开始的地方",
  text: "想写的话……",
  image: "assets/us-01.jpg",
  caption: "照片下方的小字",
  alt: "图片说明（给读屏软件）"
}
```

可以删、可以加，页面会自动生成。

### 心动清单

`config.reasons` 数组，`icon` 可选：

`sun` `sparkles` `heart` `cloud` `compass` `music` `coffee` `star`

### 照片墙

`config.gallery` 数组，`rotate` 控制每张照片的倾斜角度，例如 `"-3deg"`。

### 情书

`config.letter`：

```js
letter: {
  title: "写给{her}的一封信",
  greeting: "亲爱的{her}：",
  paragraphs: [
    "第一段……",
    "第二段……"
  ],
  signature: "永远偏爱你的，{me}",
  ps: "P.S. 今天也超级喜欢你。"
}
```

### 愿望清单

`config.wishes`，想预置已完成的愿望就写 `done: true`。  
访客点击打勾后，会保存在浏览器本地（localStorage），刷新不会丢。

### 配色

打开 **`css/style.css`**，最上面的 `:root` 里集中定义了颜色：

```css
--bg: #08070f;
--cream: #f8f0e7;
--rose: #ff9eb6;
--gold: #f1c992;
--lavender: #beaaff;
```

想换风格，改这几个颜色即可。

### 页面大标题

各章节的大标题目前写在 `index.html` 里，例如：

```html
<h2>关于我们<br><em>和那些没说完的喜欢</em></h2>
```

直接搜中文标题就能改。

## 5. 部署到网上（可选）

这个网站是纯静态的，不需要后端，也不需要构建。

最简单的方式：

- **Netlify**：把整个文件夹拖进 Netlify Drop
- **Vercel**：新建项目，导入文件夹
- **GitHub Pages**：把整个文件夹推到仓库，开启 Pages
- **自己的服务器**：把整个文件夹上传到网站目录

⚠️ 部署后照片会公开可访问。  
如果只想给她一个人看，建议加访问密码（例如 Netlify 的 Password Protection），或者只本地打开。

## 6. 小彩蛋 / 交互

- 点击右上角 **夜曲**：播放一段网页实时合成的原创氛围音乐（不是外部音频文件）
- 点击首页 **听一首给你的歌**：同上
- 点击 **信封**：拆开情书
- 点击 **照片**：放大预览，支持左右切换、Esc 关闭
- 点击 **愿望**：打勾、保存进度、爱心绽放
- 点击文末 **收下我的心**：满屏爱心 + 随机情话
- 鼠标在桌面端移动：有跟随光点和星尘
- 页面滚动：时间轴进度、章节显现、星座连线
- 手机、平板、桌面都有单独适配

背景音乐是程序实时合成的，不会涉及版权；浏览器要求用户点击后才能播放，这是正常的。

## 8. 常见问题

**打开后没有照片？**  
先确认照片确实放在 `assets/` 里，且 `config.js` 里的文件名（含大小写）完全一致。

**音乐没有声音？**  
浏览器禁止自动播放，需要点击右上角“夜曲”或首页按钮；再检查设备音量和浏览器标签页是否静音。

**改了 `config.js` 但页面没变？**  
浏览器缓存了旧文件，按 `Ctrl + F5` 强制刷新。

**“在一起第几天”不对？**  
检查 `startDate` 的时区，建议保留 `+08:00`。

**想清空愿望进度？**  
浏览器开发者工具 → Application → Local Storage → 删除 `our-story-wishes-v1`。
